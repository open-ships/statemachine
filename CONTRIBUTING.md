# Contributing

Run these checks before submitting a change:

```sh
gofmt -w .
go vet ./...
go run github.com/kisielk/errcheck@v1.20.0 ./...
go run honnef.co/go/tools/cmd/staticcheck@v0.7.0 ./...
go test ./...
go test -race ./...
go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...
```

Behavioral changes must update `CONTEXT.md`, applicable ADRs, package documentation, `SAFETY.md`, and `docs/assurance/requirements.md`. Add a regression test that names the invariant being protected. Changes to Supervisor identity, commit points, timing, Journal/Recorder behavior, Observer failure semantics, or release provenance require an explicit changelog entry and independent review.
