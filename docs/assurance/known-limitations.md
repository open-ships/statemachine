# Known limitations

- This module is not a safety controller and cannot terminate arbitrary Go code or external hardware work.
- A Journal prepares in-doubt state before Issue and receives a closure Snapshot after every commit, fault, and recovery, but it cannot atomically combine arbitrary controller I/O with durable process storage. Controllers still need fencing, expiry, and idempotency. A failed or skipped closure can leave a clean or in-doubt saved Snapshot. Every startup must reconcile application truth; a clean Snapshot is not proof that no later fault occurred.
- Supervisor Recorder and Journal timeouts bound the caller's wait, not callback lifetime. Each sink admits at most one outstanding callback per Supervisor and rejects busy delivery; a permanently blocked sink blocks further admitted operations/recovery until it ends. There is no automatic retry. TimeoutObserver has different semantics: successive timed-out observations can overlap and can each leave a blocked goroutine. A ContainedObserver reporter also needs an outer timeout if it can block.
- Snapshot validation cannot detect rollback to a valid older Snapshot. Compare Revision, Attempt, and Restarts against an independently stored durable high-water mark before trusting a restored execution; Snapshots carry no signature or provenance binding.
- Record.At, Snapshot.RecordedAt, Fault.OccurredAt, and Observation.At are wall time and are subject to clock steps (NTP or GNSS discipline). Ordering across a step is not trustworthy; Record Seq within one IncarnationID and Observation Seq within one execution are authoritative. IncarnationID ensures uniqueness, not cross-process ordering; Restarts can repeat when the same older Snapshot is restored twice.
- Record CauseText and adjudication Evidence are free text. Machine-classifiable incident taxonomies need application-side error codes carried in the causes themselves.
- Statechart keeps Source committed on entry failure, but completed exit/entry actions and external effects are not rolled back. ActionError reports partial lifecycle progress.
- Observer failure is returned after commit. Callers must not interpret that error as a failed state change; ContainedObserver separates observation failures from execution errors. It does not make a queued Run atomic: earlier events can commit before a later event fails.
- Runtime limits and Limits.MaxRecords bound admitted library work and retained history, not memory or work launched by application callbacks.
- Function values and mutable closure captures remain shared by compiled definitions. Callers must synchronize or avoid mutable captures.
- State, event, Snapshot, Record, and Observation values are shallow, and a retained Fault cause is an application-owned error value. Use immutable value types, immutable error values, and immutable evidence snapshots.
- The library prescribes no verification-evidence schema; callback data T is application-defined. The module cannot validate sensor identity, evidence age, calibration, coherence, or operator authority. A product integration must define and validate that evidence before its checks authorize progress (INT-EVID-001).
- Arbitrary application Error/String methods can block or reenter. Callback error text is captured within the owned callback budget. An uncaptured custom Trip error retains its cause but uses a type description in stored text; application error values must still be immutable.
- Counter exhaustion refuses admission before the remaining diagnostic headroom is used. At the Record ceiling, subsequent records are dropped and Status.RecordsExhausted becomes true; the application must reconcile and establish a new lineage.
- The SQLite integration suite exercises a real local database. Its lost-response test injects failure after a real commit; it does not reproduce network failures at a remote database commit point. Production adapters need database-specific isolation and fault-injection tests.
- Historical tags are retained unchanged as prerelease history. The first stable release is 1.4.0; its workflow creates annotated tags and attested release artifacts, without promising cryptographically signed tags.
